## Round 3 — tactical movement, enemy attacks, aerial boss

**Movement was redesigned at Justin's request** ("always running in a glitchy pattern"). The pilot
now fights in beats instead of strafing non-stop:

- `HOLD` — plant, face the target, let the gun work (throttle 0)
- `REPOSITION` — a 0.62 s dash to a new angle, then plant again
- `ADVANCE` / `BACKOFF` — bounding moves: 0.9 s push, 1.9-2.5 s pause to shoot
- `RETREAT` — 0.8 s bounding retreat when integrity is low
- `DODGE` — boss telegraph break-off

The renderer now eases velocity (`k = 10`) instead of snapping position, so starts and stops are
smooth.

Measured (`node tools/movement.mjs`): **82.8 m travelled per 60 s** (target 55-90), **0 frozen
frames**, camera push **0 m**, 18-39 hold beats per run, max frame velocity change 1.4-1.6 m/s
(eased, no snaps).

**Enemy attacks were stubs.** Only melee ever reached the player — that is why an autonomous pilot
could never lose. `rangedShot`, `dive`, `shell`, `stomp`, `minigun`, `charge` and `paint` now apply
damage/effects with line-of-sight and range gates.

**TUNE-04 gunship:** aerial boss now uses `TUNING.boss.gunship.hp` (900) instead of the ground
`bossHp()` (+2600 flat). Measured TTK **11 s** with flak (target 8-15 s), firing from **6.75 m**
altitude. The single-shot path also had to use `effectiveDamage` — anti-air/lit/explosive modifiers
were being computed and then ignored.

**TUNE-02 difficulty:** `difficulty.hpMult = 3.0`, `hpScaling = 0.24`; runs now end in death instead
of sitting at the cap. Tables in `docs/TUNE.md` (with cards) and `docs/evidence/tune-nocards.txt`
(no upgrades).

## Bugs found by measuring

1. **The game clock ran at 2x.** `main.js` incremented `beatDirector.runTime` and
   `beatDirector.update(dt)` incremented it again. Every beat, spawn rate, difficulty ramp, XP/s and
   boss threshold was double speed. Removed; a 60 s wall-clock run now reports 60 s of game time.
2. **Results screen printed raw floats** (`60.5000000000000049`). `director.js` now rounds to one
   decimal.
3. **Objective banner overlapped the darkness banner.** Darkness now uses `HUD_SLOTS.statusBanner`.
4. **Air-damage read `effectiveDamage` before it was declared** (TDZ throw on any flak shot). Fixed.
5. **Death never reached the results screen.** `hurt()` parked the run in `dead`; fixed.
