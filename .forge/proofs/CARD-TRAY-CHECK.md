# Card Tray Verification

## Manual Verification Steps

1. Power on the device and ensure the system is in a stable state.
2. Open the card tray access panel located on the left side of the device.
3. Visually inspect the tray for any visible damage, debris, or misalignment.
4. Insert a standard test card (e.g., a blank ISO 7810-compliant card) into the tray.
5. Confirm the card is fully seated and detected by the system.
6. Check the status LED on the tray module; it should illuminate green when a card is properly recognized.
7. Use the device's built-in diagnostics menu (accessible via the main menu > Tools > Card Tray Check) to verify card presence and read status.
8. If the system fails to detect the card, remove and reinsert it, then retry.
9. If detection continues to fail, contact technical support for further troubleshooting.

## Quick Verification Note

For a rapid manual check: power on, open tray, insert test card, confirm green LED and diagnostics menu shows "Card Present". If LED stays red or menu shows "No Card", re-seat once before escalating.
